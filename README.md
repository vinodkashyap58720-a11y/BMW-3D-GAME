## 📲 How to Install

You can install Drift King 3D on supported devices using Google Chrome.

### Android Installation

1. Open the [Drift King 3D website](https://vinodkashyap58720-a11y.github.io/drift-king/) in Google Chrome.
2. Tap the three-dot menu (⋮).
3. Select **Install app** or **Add to Home screen**.
4. If prompted, tap **Install** or **Create shortcut**.
5. Wait a little while for the installation to complete.
6. Open Drift King 3D from your home screen!

> 💡 **Offline Support:** After opening the game online and allowing its required files to load and cache, you can play offline. Some features may still require an internet connection.
